**Behoben**
- Odyle-Energie: Das Meter merkt sich die Energie jetzt je Charaktername und Server. Hast du gleichnamige Charaktere auf verschiedenen Servern, zeigten sie sich gegenseitig die Energie des anderen. Solange der Server nicht bekannt ist, wird keine gemerkte Energie angezeigt.
- Ein-/Ausblende-Taste (und Tray-Klick): Hatte die automatische Ausblendung, „Außerhalb des Kampfes ausblenden“ oder die Solo-Regel das Meter minimiert, brauchte es zwei Tastendrücke, bis es zurückkam. Jetzt holt schon der erste Druck das Meter wieder.
- Buff-Zeitleiste (Details): Buffs, die das Spiel nie anzeigt (zum Beispiel der unbenannte Balken nach einem Ausweichen), sind ausgeblendet. Unbenannte Buffs tragen den Namen des Skills, der sie auslöst. Wechselt ein Effekt auf einen anderen, wird der alte beendet und der neue beginnt – ein zweites „Macht des Sturms“ erschien vorher als „Segen der Erde“.

**Sonstiges**
- Plugins mit Erlaubnis für den Schwarzwolken-Händler sehen jetzt auch, welche Waren du in diesem Angebot schon gekauft hast (ausverkauft). Ohne Erlaubnis bekommt kein Plugin etwas.
- Basis jetzt A2Tools 2.0.95.
- Alle Fork-Funktionen bleiben erhalten. Das Teilen von Daten (Synchronisieren, Bosskämpfe, Ranglisten, Party-A2-Tag) bleibt aus, bis du es selbst einschaltest.

**Installation (neu)**
1. `AION2-DPS-Meter_3.0.36_x64.msi` herunterladen und ausführen. Windows SmartScreen warnt, weil der Installer nicht signiert ist: „Weitere Informationen“ → „Trotzdem ausführen“.
2. Npcap: Fehlt es, bietet der Installer an, es nach dem Setup herunterzuladen (Haken gesetzt lassen, Npcap-Setup mit den Standardoptionen durchklicken). Sonst fragt das Meter beim ersten Start danach.
3. Meter starten, im Spiel einloggen. Updates kommen danach automatisch (Meldung beim Start).
4. Einstellungen → „Gruppe teilen“: Einladungslink einfügen.
