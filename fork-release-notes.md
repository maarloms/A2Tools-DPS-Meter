**Behoben**
- Das Meter hat zeitweise Datenmüll als deinen Charakternamen gelesen („b“, „V“, „8Z“ …), sich unter diesem Namen beim Gruppenraum angemeldet und Kämpfe so hochgeladen. Ein Name aus dem Spiel zählt jetzt nur noch, wenn Server und Klasse dazu passen.
- Ein getippter Charaktername geht erst an den Gruppenraum, wenn er eine Weile steht, und Uploads nur unter einem Namen, der im Kampf vorkommt.

**Gruppenraum**
- Der Raum lässt nur noch die eingetragenen Mitglieder herein. Steht dein Name nicht in der Liste, zeigt das Meter das unter „Gruppe teilen“ an.

**Installation (neu)**
1. `AION2-DPS-Meter_3.0.10_x64.msi` herunterladen und ausführen. Windows SmartScreen warnt, weil der Installer nicht signiert ist: „Weitere Informationen“ → „Trotzdem ausführen“.
2. Npcap: Fehlt es, bietet das Meter beim ersten Start an, es herunterzuladen und zu installieren (Standardoptionen übernehmen, danach Meter neu starten).
3. Meter starten, im Spiel einloggen. Updates kommen danach automatisch (Meldung beim Start).
4. Einstellungen → „Gruppe teilen“: Einladungslink einfügen.
