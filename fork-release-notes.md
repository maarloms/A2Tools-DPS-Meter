**Neu**
- Plugins können ihr eigenes Fenster jetzt selbst ein- und ausblenden, ohne dem Spiel den Fokus zu nehmen. Dafür gibt es eine eigene Berechtigung („Sein eigenes Fenster ein- und ausblenden“), die vor der Installation angezeigt wird.
- Plugin-Fenster öffnen sich beim nächsten Start wieder – ausgeblendete bleiben ausgeblendet und arbeiten im Hintergrund weiter. Wer ein Plugin-Fenster mit dem X schließt, bekommt es beim nächsten Start nicht wieder.
- Plugins können erkennen, welche Aktionen von deinem eigenen Charakter kommen, ohne die Daten anderer Spieler zu sehen.
- Neuere Plugins (Plugin-Schnittstelle 2) lassen sich jetzt installieren; ältere laufen weiter wie bisher.

**Behoben**
- Plugin-Seiten laden ihre eigenen Dateien zuverlässiger (genauere Sicherheitsregeln je Plugin).

**Sonstiges**
- Basis aktualisiert auf A2Tools 2.0.62 (aktueller Stand). Die Änderungen betreffen vor allem Plugins; Meter, Event-Timer, Overlay und „Gruppe teilen“ funktionieren wie bisher.

**Installation (neu)**
1. `AION2-DPS-Meter_3.0.18_x64.msi` herunterladen und ausführen. Windows SmartScreen warnt, weil der Installer nicht signiert ist: „Weitere Informationen“ → „Trotzdem ausführen“.
2. Npcap: Fehlt es, bietet das Meter beim ersten Start an, es herunterzuladen und zu installieren (Standardoptionen übernehmen, danach Meter neu starten).
3. Meter starten, im Spiel einloggen. Updates kommen danach automatisch (Meldung beim Start).
4. Einstellungen → „Gruppe teilen“: Einladungslink einfügen.
