**Behoben**
- Mit geöffneten Einstellungen hing die App alle paar Sekunden für 1–6 Sekunden.
- Wurde das Meter einmal als Administrator gestartet, speicherte es danach im normalen Start keine Einstellungen und Kämpfe mehr.
- Das Öffnen der Einstellungen setzte den Zielmodus (z. B. GROUP) im laufenden Kampf zurück.
- Der TTK-Schalter zeigte in den Einstellungen „aus“, obwohl TTK an war.

**Geändert**
- Einstellungen wirken sofort im Meter, ohne den Kampf zurückzusetzen.
- Das Einstellungsfenster öffnet schneller.
- Meter-Fenster schließen beendet die App (Kämpfe werden gespeichert). Ist der Event-Timer offen, bleibt er stehen: das Meter wird nur ausgeblendet (zurück per Ein-/Ausblenden-Hotkey), und erst das Schließen des Timers beendet die App.

**Sonstiges**
- Basis aktualisiert auf A2Tools 2.0.54.

**Installation (neu)**
1. `AION2-DPS-Meter_3.0.13_x64.msi` herunterladen und ausführen. Windows SmartScreen warnt, weil der Installer nicht signiert ist: „Weitere Informationen“ → „Trotzdem ausführen“.
2. Npcap: Fehlt es, bietet das Meter beim ersten Start an, es herunterzuladen und zu installieren (Standardoptionen übernehmen, danach Meter neu starten).
3. Meter starten, im Spiel einloggen. Updates kommen danach automatisch (Meldung beim Start).
4. Einstellungen → „Gruppe teilen“: Einladungslink einfügen.
